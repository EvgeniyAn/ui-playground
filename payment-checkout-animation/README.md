# Interactive Payment Checkout

Откройте `index.html` в браузере — сборка, зависимости и сервер не нужны.

Самостоятельное воссоздание checkout из ролика code.xr на HTML, CSS и JavaScript. Введите тестовые данные: лицевая сторона обновляется сразу, фокус на CVV переворачивает карту. Кнопка оплаты убирает форму, перемещает карту в центр и включает красное свечение. После имитации обработки свечение становится зелёным и рисуется галочка. `Try again` возвращает форму с введёнными данными.

Это визуальное демо: сетевых запросов, хранения реквизитов и реальной оплаты нет. Надписи о защите — декоративные элементы исходного дизайна. Используйте вымышленные данные. Предзаполненные данные позволяют сразу запустить эффект.

Состояния изолированы внутри компонента. Переходы ожидают `Animation.finished`, повторная отправка блокируется. Поддерживаются клавиатура, узкий экран и системная настройка уменьшения движения. Для мобильного экрана исходные колонки расположены вертикально; в конце добавлена кнопка повтора.

Исходный ролик и кадры: `../video-reference-tool/downloads/2026-09-08-code.xr-Interactive-Payment-Checkout/`. Исходные материалы не изменены. Неполный React/Framer Motion код из видео не копировался.
