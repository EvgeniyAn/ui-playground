# Paper plane Send

Откройте `index.html` напрямую в браузере. Сервер и зависимости не нужны.

Две независимые кнопки: Send → складывание листа → поворот на 55° → полёт вправо вверх → ✓ Sent. Повторное нажатие Sent запускает анимацию заново. Replay и Escape сбрасывают обе кнопки, в том числе во время полёта. Tab + Enter/Space работают как у обычных кнопок. При reduced motion результат появляется сразу. Это визуальная демонстрация, сетевой отправки нет.

https://www.instagram.com/reel/Dc3-6HCvMpL/

Исходные материалы: `../video-reference-tool/downloads/2026-09-10-code_and_chill_-send-button-paper-plane-pure-CSS-no-JS-loop/` (manifest: complete). Дополнительная выборка: `../video-reference-tool/downloads/2026-09-10-video-2/`.

Наблюдения: светлая панель с двумя прямоугольными кнопками, чёрная и фиолетовая бумага с более светлым центральным сгибом; после полёта остаётся приглушённая кнопка Sent. Первый запуск начинается примерно на 0.95 с, складывание длится около 0.45 с, поворот — 0.23 с, полёт — 0.34 с. Титры и редактор исключены.

Это самостоятельное воссоздание по кадрам: точные исходные координаты и easing не видны. Replay, отмена и повторное нажатие добавлены для удобства; автоматический сброс в ролике не продемонстрирован. Анимации используют Web Animations API, фазы ожидают `Animation.finished`; у каждого экземпляра свои отменяемые анимации.

## Проверки

- `node --check script.js` — пройдено; все локальные ресурсы существуют.
- Изолированная проверка логики с имитацией завершения Web Animations: одновременный запуск двух кнопок, быстрые повторные клики, оба порядка поочерёдного запуска, Replay во время анимации, Escape с немедленным перезапуском, reduced motion — пройдено.
- Браузерная политика заблокировала открытие file URL. Реальные промежуточные кадры, визуальное сравнение, клавиатура и узкий экран в браузере не проверены. Имитация анимаций проверяет управление состояниями, а не качество отрисовки.
