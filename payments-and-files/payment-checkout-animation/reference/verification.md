# Повторная проверка 2026-09-08

Полный цикл проверен в Chrome через локальный HTTP-сервер. Предыдущие таймауты не помешали повторной проверке.

- Ввод имени, номера, даты и CVV обновляет карту. Номер группируется, лишние символы CVV удаляются.
- Пустое имя и месяц 13 отклоняются; неверная дата оставляет форму в исходном состоянии.
- Фокус CVV переворачивает карту; уход из поля возвращает лицевую сторону. В браузере осмотрены обратная сторона и реальный промежуточный кадр анимации, приостановленной на 170 ms.
- Проверены обработка с красным свечением, завершение с зелёным свечением и галочкой, возврат формы. Смена данных сохраняется при повторе.
- Клавиатура: Tab из CVV, Enter для отправки и Enter на Try again; после повтора фокус возвращается в поле имени.
- Тестовый стенд выполнил три цикла; в каждом три requestSubmit подряд в одном JS-задании. Дубли блокируются, форма inert, кнопка отключена; после успеха и повтора состояние корректно восстанавливается. 15 проверок прошли, см. interaction-results.txt.
- Три цикла с имитацией JS matchMedia prefers-reduced-motion прошли, включая проверку короткой длительности (18 проверок). См. reduced-motion-results.txt. Это проверка JS-ветки с подставленным media preference; системная настройка macOS не менялась, реальное системное CSS media query отдельно не эмулировалось.
- На CSS-ширинах 375 и 320 px проверены форма и успешное завершение. На 320 px найдены и исправлены обрезание последнего шага шапки и номера в поле: уменьшены отступы/шрифт. После исправлений повторно осмотрены начальное и конечное состояния, выполнен повтор. Горизонтального переполнения страницы нет.
- Консоль Chrome в проверенных сценариях: без ошибок и предупреждений. node --check script.js проходит.

В comparison.jpg исходная панель и реализация приведены к ширине 1040 px. Геометрия близка; системный шрифт, иконки, рисунок карты и микротекст приблизительные. Исходный кадр содержит незавершённый номер, демо — полный номер. Скриншот desktop.jpg снят при CSS viewport 1300×1050, mobile-320.jpg — 320×750.

Стенд reference/checks.html оставлен для повторных проверок. Запуск из папки проекта: python3 -m http.server 8081 --bind 127.0.0.1, затем http://127.0.0.1:8081/reference/checks.html. Кнопки запускайте последовательно после ALL CHECKS PASSED. Переключатель reduced-motion подставляет только JS matchMedia в тестовом iframe. Сам checkout открывается без сервера.

Тестовые вкладки закрыты, временный сервер остановлен, освобождение 8081 проверено. Другие браузеры и устройства не тестировались.
