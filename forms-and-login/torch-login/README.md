# Torch login

Откройте `index.html` напрямую в браузере. Сервер и интернет не нужны.

Персонаж идёт 2,75 с, включает луч (0,65 с), затем свет проявляет форму (1,3 с). `tap to skip` или Escape пропускают вступление; Replay запускает его заново. Все кнопки доступны с клавиатуры. При `prefers-reduced-motion` форма появляется сразу. Есть проверка email/пароля браузером, показ пароля и локальная обратная связь. Вход, восстановление и регистрация не подключены к серверу; данные не отправляются и не сохраняются.

Референс: https://www.instagram.com/reel/DdBsRvDsMeh/
Исходный ролик и полные кадры: `../../video-reference-tool/downloads/2026-09-19-codeme.live-Creative-Login-Page-UI-Torch-Flashlight-Animation-Effect/`.
Кадры персонажа получены существующим инструментом из области 65,845,180,165, 0–2,75 с; отдельный bundle: `../../video-reference-tool/downloads/2026-09-19-video-2/`. В assets лежат только производные кадры персонажа. Персонаж имеет исходное растровое разрешение; форма и свет созданы независимо средствами HTML/CSS. Титр и редактор кода в демо не включены. Поведение формы после отправки в ролике не показано и добавлено для демонстрации.

Проверки: синтаксис JS, наличие ресурсов и 42 PNG; логика фаз, ожидание завершения, 12 быстрых Replay/skip, отмена при включении света, Escape, reduced motion, показ пароля и локальная отправка проверены в Node с имитацией DOM/Animation. Браузерная проверка, скриншоты и проверка узкого экрана не выполнены: браузерный инструмент запретил file:// своей политикой безопасности.
