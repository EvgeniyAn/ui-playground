# Payment Checkout V3

Откройте `index.html` напрямую в браузере. Установка, сборка и сервер не нужны.

Нажмите **Pay Now**: кнопка показывает обработку, сжимается в квадрат, поднимается в центр и превращается в жетон внутри фиолетовых колец. Процент и дуга показывают проверку; затем появляется зелёная галочка, подтверждение заказа и конфетти. Весь переход занимает примерно шесть секунд.

- **Replay animation** запускает анимацию заново, в том числе во время предыдущего запуска.
- Строка **VISA** раскрывает сведения о демонстрационной карте.
- **View Order Details** открывает локальное окно заказа; **Done**, крестик или Escape закрывают его.
- Учтена системная настройка уменьшения движения. Данные карты и сумма фиксированы для демонстрации; сетевых запросов, сохранения данных и реального платежа нет.

Самостоятельное воссоздание элемента из [ролика code.xr](https://www.instagram.com/reel/DcGgytAzym7/) на HTML/CSS/JS. Заголовок видеоролика, промо и панель исходного кода исключены. Шрифт, easing и тайминги приближены по кадрам. На узком экране карточка сужается, а высота и размеры текста адаптируются для читаемости.

Файлы: `index.html` — структура; `style.css` — внешний вид; `script.js` — последовательность анимаций, отмена и локальные взаимодействия. Материалы исходника находятся отдельно в `../video-reference-tool/downloads/2026-09-10-code.xr-code.xr-Interactive-Payment-Checkout-v3/`. Разбор кадров — `reference/observations.md`.

## Проверка

Проверены синтаксис JavaScript и ссылки на локальные CSS/JS. Код не содержит внешних запросов или хранилища. Внешний вид исходника изучен по 24 кадрам и дополнительной серии перехода.

Открытие локального HTML инструментом браузера отклонено политикой безопасности URL. Поэтому внешний вид реализации, промежуточная отрисовка, взаимодействия в настоящем браузере и узкий экран **не проверены**. Подробности — `reference/verification.md`.
