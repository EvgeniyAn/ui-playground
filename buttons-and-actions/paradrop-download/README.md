# Paradrop download

Откройте `index.html` напрямую в браузере. Сервер и зависимости не нужны.

Нажмите круглую кнопку: кольцо разворачивается в прогресс-бар, стрелка переворачивается, раскрывает парашют и опускается; в конце появляется галочка. `Cancel` или Escape отменяет анимацию, `Replay` запускает заново. Кнопки работают с Tab, Enter и Space. При reduced motion полёт пропускается.

Это демонстрация интерфейса: процент имитируется, файл не скачивается. Время после нажатия: раскрытие 300 мс, спуск 2350 мс, приземление 280 мс. Визуальная реконструкция по кадрам, не исходный код автора.

Проверки: `node --check script.js`, наличие локальных ресурсов и кадров. Логика проверена в Node VM с имитацией DOM и кадров: быстрые повторные вызовы, завершение, Cancel, Escape, Replay и немедленный перезапуск; обычный и reduced-motion режимы. Это не проверка отрисовки браузером. Браузерный инструмент заблокировал file URL политикой безопасности, поэтому сравнение скриншотов, фактическая клавиатурная навигация и узкий экран остаются без визуальной проверки.
