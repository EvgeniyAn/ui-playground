# Bulk delete cards

Откройте `index.html` напрямую в браузере — сервер, сборка и зависимости не нужны.

Две независимые версии из референса: Basic плавно сжимает выбранные карточки (560 мс с небольшим сдвигом по времени), затем перестраивает сетку и уменьшает блок (380 мс); Premium подсвечивает выбор, показывает счётчик и отправляет карточки в корзину с круговым прогрессом. Клик по карточке или Space на чекбоксе выбирает папку, кнопка удаления запускает действие. Replay восстанавливает все шесть карточек и прерывает текущую анимацию. Escape внутри демо отменяет текущую анимацию; после завершения удаления восстановление доступно через Replay. Удаляются только карточки демо в памяти страницы.

Поддерживаются клавиатура, узкий экран и `prefers-reduced-motion`. В этом режиме удаление происходит сразу. Обе версии можно использовать независимо и одновременно.
