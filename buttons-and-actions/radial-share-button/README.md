# Radial share button

Откройте `index.html` напрямую в браузере. Сервер, сборка и зависимости не нужны.

Нажмите **SHARE**, затем выберите канал. Кнопка ссылки копирует URL референса; X, LinkedIn, WhatsApp и email открывают форму отправки. Автоматической публикации нет. Чтобы изменить ссылку, отредактируйте `shareURL` в `script.js`.

**Replay** возвращает начальное состояние. **Escape** отменяет любой этап. Поддерживаются Tab, Enter, Space и стрелки для выбора канала. При `prefers-reduced-motion` переходы происходят без движения. Если браузер запрещает буфер обмена, показано сообщение об ошибке.

Референс: https://www.instagram.com/reel/DdcMKv9z9-T/

Материалы: `../../video-reference-tool/downloads/2026-09-19-code_and_chill_-Radial-share-button-animation/` (manifest: complete).

Наблюдения: белая капсула SHARE на бежевом фоне; после клика сжатие в центральный круг, пять белых дисков раскрываются слева направо по дуге (X, LinkedIn, WhatsApp, email, ссылка). Выбранный диск заполняется цветом от точки нажатия, остальные сходятся и исчезают; выбранный возвращается в центр, становится белым с галочкой. Подписи: Pick a channel → Copying… → Link copied.

Тайминг в записи: нажатие около 1.2 с, раскрытие закончено около 2.0 с; выбор ссылки около 3.6 с, перемещение в центр до 4.2 с, галочка около 4.6 с. Геометрия уменьшена до CSS-масштаба: кнопка 180×68, диски 60, шаг дуги 46°. Иконки — локальный SVG, независимая реализация. Заголовок ролика, редактор и подпись автора исключены. Replay, отмена и поведение других каналов добавлены для работоспособности демо: в видео показано только копирование ссылки.

Проверено в Chromium через `file://`: начальное состояние, раскрытие, копирование, финал, Replay, быстрые повторные клики, управление клавиатурой, Escape во время выбора, ширина 320 px, reduced motion и отказ буфера обмена. Ошибок JavaScript нет; синтаксис и локальные ресурсы проверены. Скриншот раскрытого компонента сопоставлен с кадром видео в одинаковом масштабе, просмотрены промежуточные состояния. Safari/Firefox и отправка через реальные аккаунты не проверялись.
