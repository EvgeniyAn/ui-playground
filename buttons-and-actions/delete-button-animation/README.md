# Delete Button — The Bin Eats The Label

Самостоятельная реализация элемента из [ролика @_code_and_chill_](https://www.instagram.com/reel/Dc-QVVMzfb0/).
Чистые HTML, CSS и JavaScript; без сборки, внешних библиотек и сетевых запросов при запуске.

## Запуск

Откройте `index.html` в современном браузере. Или запустите из этой папки:

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Перейдите на `http://127.0.0.1:8080`. Нажмите любую кнопку, в том числе с клавиатуры (Tab, Enter или пробел).
После завершения она автоматически возвращается в исходное состояние. Обе кнопки работают независимо.
Это демонстрация: реальные файлы не удаляются.

## Разбор референса

В ролике две объёмные кнопки-капсулы на светлой панели: фиолетовая и графитовая.
Эффект строится на последовательности небольших движений:

1. Корзина наклоняется, крышка открывается.
2. Буквы `Delete` по очереди летят по дуге внутрь корзины.
3. Каждая приземлившаяся буква поднимает уровень заполнения.
4. Крышка закрывается, капсула сжимается в круг, корзина перемещается в центр.
5. Внешняя дуга вращается, замыкается в кольцо, корзина опустошается.
6. Кнопка раскрывается, надпись возвращается.

Внизу видео показаны только фрагменты исходников, поэтому это не дословная копия кода автора.
Пропорции, цвета и последовательность восстановлены по кадрам. Длительности подобраны визуально.
`reference/frame.png` — исходное состояние, `reference/sequence.jpg` — последовательность кадров ролика.
Окружение видео с исходным кодом не включено в интерфейс: воспроизводится сам элемент.

## Файлы и настройка

- `index.html`: два экземпляра кнопки и анимируемые SVG-части корзины.
- `style.css`: оформление, адаптивный размер, крышка, заполнение, сжатие и кольцо.
- `script.js`: независимые состояния и траектории букв через Web Animations API.
- `assets/`: локальный шрифт Nunito (Google Fonts), лицензия SIL OFL.

Цвета вариантов задаются переменными `--top`, `--ink`, `--bottom` и `--shadow`.
Скорость полёта и задержки находятся в `eatLabel()`. Паузы фаз — в обработчике `click`.
Высота заполнения меняется после `animation.finished` каждой буквы.
При `prefers-reduced-motion: reduce` полёт и вращение заменяются кратким подтверждением.
Повторные нажатия во время анимации игнорируются; фокус клавиатуры сохраняется.

В оригинальном фрагменте JS есть ожидание запроса удаления. Здесь оно заменено фиксированной
демонстрационной фазой кольца; подключение API не требуется и не реализовано.
