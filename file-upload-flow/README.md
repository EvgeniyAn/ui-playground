# File upload flow

Откройте `index.html` напрямую в браузере. Сборка, сервер и библиотеки не нужны.

Нажмите **Play demo**: пять строк одновременно демонстрируют прогресс, успешное завершение, отклонение PSD и файла больше 50 MB, а также сбой соединения с независимым Retry. **Replay demo** полностью перезапускает пример. × отменяет строку, Escape — все текущие загрузки. Replace позволяет выбрать другой файл вместо неподходящего. Clear finished убирает завершённые, ошибочные и отменённые строки.

Можно выбрать, перетащить или вставить свои файлы. Проверяется расширение и размер до запуска. Это локальная симуляция: содержимое файлов не читается, никуда не отправляется и не сохраняется. Проценты, скорость и завершение имитируют передачу. Проверка расширения не заменяет проверку содержимого на сервере в настоящем продукте.

Референс: https://www.instagram.com/reel/Dc5WPlDBSj0/

В видео шесть отдельных сравнений плохого и хорошего UX, а не один непрерывный экран. Здесь положительные варианты объединены в один загрузчик: фон, панели, голубые полосы прогресса и розовые ошибки воссозданы по кадрам; титры, сравнения и реклама исключены. Геометрия объединённого экрана и длительности интерактивной демонстрации — адаптация. Строки появляются плавно, прогресс движется линейно, затем каждая независимо переходит в успех/ошибку; повтор сбрасывает только выбранную строку. Учтены клавиатура, узкие экраны, reduced motion и сворачивание панели активности.

Исходное видео и 24 кадра сохранены отдельно в `../video-reference-tool/downloads/2026-09-10-motion_ui_interface-48-MB-uploaded.-Then-it-told-you-.psd-isn-t-supported/` (manifest: complete).

Проверено: `node --check script.js`, разбор HTML и наличие локальных ресурсов. Изолированная проверка JS с минимальным DOM и управляемыми кадрами подтвердила одновременные строки, быстрый Replay, остановку прогресса при отмене, независимый Retry, завершение, Escape, очистку и границу 50 MB. Это проверка логики, не отрисовки. Браузерный инструмент запретил открытие file URL; реальные скриншоты, выбор/перетаскивание/вставка файлов, узкий экран и reduced motion в браузере не проверены.
