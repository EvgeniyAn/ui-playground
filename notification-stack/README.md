# Notification Stack

Откройте `index.html` напрямую в браузере. Сервер, сборка и интернет не нужны.

Два независимых блока из [референса](https://www.instagram.com/reel/DdCCk3fiO0M/): Basic — список с удалением любой карточки, Premium — полупрозрачная стопка с передней карточкой, счётчиком и индикаторами.

- Нажмите × для удаления; Tab и Enter/Space работают с кнопками.
- Replay восстанавливает оба блока, включая во время анимации.
- Escape отменяет текущую анимацию. Если карточка уже удалена, отменяется только перестроение; вернуть всё можно через Replay.
- Повторные нажатия блокируются на время перехода. Блоки имеют независимые состояния.
- Учтены узкие экраны и системная настройка reduced motion.

## Наблюдения и реализация

Ролик 1080×1920, 11.774 с. Начальный блок Basic примерно 672×568 px, Premium 672×389 px; демо нормализовано до ширины 448 CSS px. Светло-серый фон, белые скруглённые панели, пастельные пиктограммы. Сначала в Basic убираются Follower и Comment. Примерно с 7.5 с передние карточки Premium последовательно уходят вниз с исчезновением, следующая выходит вперёд; счётчик уменьшается, число точек сокращается. Реплика выполнена самостоятельно на HTML/CSS/JS, видимые фрагменты кода не копировались как полный исходник.

Время удаления Premium — приблизительно 450 мс; перестроение — 360 мс. Ожидание через Animation.finished. Точный шрифт и кривая движения неизвестны: использован локальный системный шрифт и визуальное приближение easing. Replay, отмена и пустое состояние добавлены для демо — в ролике они не показаны. Титры, реклама и редактор кода исключены.

Материалы: `../video-reference-tool/downloads/2026-09-10-designcodewithav-Notification-Stack-UI-Upgrade-Basic-vs-Premium-HTML-CSS-JS/`. Плотная выборка перехода 7.05–7.8 с: `../video-reference-tool/downloads/2026-09-10-video-3/`.

## Проверка

`node --check script.js` проходит. Проверены наличие локальных ресурсов, уникальность HTML id, баланс фигурных скобок CSS и целостность обеих папок видеоматериалов. Браузерный инструмент запретил открытие file URL своей политикой безопасности; обход не выполнялся. Скриншоты реализации, реальные переходы, одновременные клики, Replay, клавиатура, узкий экран, reduced motion и консоль браузера не проверены в живом браузере. Для ручной проверки откройте файл, удалите все карточки, повторите через Replay, нажмите Replay и Escape во время удаления и попробуйте оба блока одновременно.
