# Signature Sidebar

Откройте `index.html` напрямую в браузере. Сервер, сборка и интернет не нужны.

- Язычок со стрелкой справа сворачивает панель в компактную полосу иконок (82 px) и разворачивает обратно (276 px). Ширина, отступы, аватар и высота пунктов меняются одной плавной анимацией; подписи гаснут до сужения и появляются после расширения. Метка под заголовком показывает текущее состояние.
- Щелчок по пункту делает его активным; светящаяся метка на левой кромке переезжает к нему.
- ⌘K (Ctrl K вне macOS) фокусирует поиск. Если панель свёрнута, она сначала раскрывается, а фокус ставится после окончания анимации ширины; повторное нажатие на язычок за это время отменяет фокусировку.
- Поиск подсвечивает подходящие пункты, Enter открывает первый найденный, Escape очищает поле и снимает фокус.
- Клавиатура: Tab по элементам, ↑/↓, Home/End внутри меню. В свёрнутом виде при наведении и фокусе рядом с иконкой появляется подпись.
- При `prefers-reduced-motion: reduce` переходы мгновенные. На узком экране текст переносится под панель.

## Референс и точность

Источник: https://www.instagram.com/reel/DdT_Y-qpanC/

Материалы сохранены отдельно в `../../video-reference-tool/downloads/2026-10-05-steacode-STEA-CODE-DROP/` (manifest: complete), частые выборки переходов — `2026-10-05-video-4` (раскрытие, 2,5–3,2 с) и `2026-10-05-video-5` (сворачивание, 8,3–9,0 с).

Воссозданы тёмная сетка фона, панель с градиентом, логотип, профиль со статусом, разделитель, поле поиска с подсказкой ⌘K, семь пунктов с иконками, активная плитка, полоса на левой кромке (синяя с янтарным участком внизу и яркой меткой у активного пункта), подпись внизу и язычок переключения. Размеры сняты с кадров (масштаб видео ≈ 1,35 px на CSS-пиксель): высота пункта 49 px с шагом 55 px в развёрнутом виде и плитка 45 px с шагом ≈ 57 px в компактном. Аватар вырезан из кадра ролика, поэтому его чёткость ограничена видеозаписью. Иконки нарисованы заново в SVG.

В ролике переход между состояниями почти мгновенный (1–2 кадра при 30 fps, затем панель доезжает до центра), хотя в описании заявлена плавная анимация. В демо переход длится около 460 мс с плавным замедлением; это интерпретация, а не измерение. Подсветка совпадений поиска, Enter, всплывающие подписи компактного режима и навигация стрелками добавлены для демо: в ролике видно только, что набранный текст не скрывает пункты, а Escape очищает поле. Титры «Full Code / Link in bio» и редактор кода из ролика не перенесены.

Проверено в Chrome при прямом открытии `file://`: сравнение скриншотов с кадрами 1,3 с и 3,5 с в одном масштабе, промежуточные кадры обеих анимаций, ⌘K из свёрнутого состояния (реальным нажатием), отмена фокусировки повторным переключением, пять быстрых нажатий подряд, выбор пункта, поиск, Enter, Escape, подписи компактного режима, ширина 375 px без горизонтальной прокрутки. Консоль без ошибок. Системный reduced motion в браузере не проверялся: инструмент не умеет его эмулировать, поведение задано только CSS-правилом.
