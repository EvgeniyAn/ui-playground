# Bikeville — IF Mode

Откройте `index.html` непосредственно в браузере. Сервер, сборка и интернет не нужны.

- Выберите категорию и вариант колёс, педалей, седла или руля.
- При загрузке велосипед появляется сложенным и автоматически раскрывается. Раннее переключение деталей, Reset, Replay или Escape отменяет вступление; при reduced motion сразу показан раскрытый велосипед.
- Кнопки слева складывают и раскрывают велосипед.
- Replay показывает последовательность изменений; Stop или Escape отменяет её. Reset возвращает исходную конфигурацию.
- Управление доступно через Tab и Enter/Space. При `prefers-reduced-motion` анимации отключены.
- Add to Cart открывает демонстрационную сводку. Покупки и отправка данных не выполняются.

Материалы сохранены отдельно в `video-reference-tool/downloads/2026-09-25-607-reactions-35-shares-Síguenos-para-más-contenido-software-softwareengineer-website-development-developer-Memes-del-codigo/` (manifest: complete).

В видео: панель примерно 783 × 482 px, левая тёмная часть занимает 37.5%; сначала раскрывается велосипед, затем меняются колёса (примерно 3–4 с), седло (5–8 с), руль (8–11 с). В конце виден переход на другой экран. Мемные вставки исключены.

Велосипед перерисован в SVG по крупным фотографиям производителя: литые трёхлучевые колёса, покрышки, обода, тормозные диски, монококовая рама, кожух цепи, рулевая стойка с вырезом, крепёж, седло, педали и грипсы. Это самостоятельная векторная интерпретация, не исходная фотореалистичная 3D-модель. Складывание схематическое, не физически точная кинематика IF Mode. Длительности анимаций приблизительные. Мобильная компоновка, цены вариантов, корзина, справочные окна и управление повтором добавлены для демо; исходный ролик их полностью не показывает. Финальный переход к другой странице из ролика не воспроизводится.

Проверены синтаксис JavaScript и локальные ссылки. Открытие file:// заблокировано политикой доступного браузерного инструмента, поэтому реальные скриншоты, переходы, узкий экран и reduced motion в браузере не проверены. Превью каталога — SVG-иллюстрация, не скриншот.
