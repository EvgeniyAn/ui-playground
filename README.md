# HTML / CSS / JS — UI Collection

Open [index.html](index.html) directly in your browser to browse all 36 projects with screenshot previews. Each project opens in a new tab. No build step or dependency installation is required.

## Projects

The folders match the groups in the catalog:

| Folder | Projects | Examples |
| --- | ---: | --- |
| [forms-and-login](forms-and-login/) | 9 | Login forms, registration, OTP verification, bug reports, radio buttons, and checkboxes |
| [buttons-and-actions](buttons-and-actions/) | 6 | Sharing, ordering, sending, downloading, and deletion animations |
| [payments-and-files](payments-and-files/) | 4 | Checkout demos, a payment card with a theme toggle, and file uploads |
| [navigation-and-cards](navigation-and-cards/) | 11 | Menus, carousels, profile and product cards, notifications, a calendar, and slideshows |
| [animations-and-effects](animations-and-effects/) | 6 | A 3D landing page, scroll progress, a bouncing square, social icons, loaders, and counters |

Each project has its own `index.html`, styles, scripts where needed, and local assets. Project READMEs, where available, explain the controls and demo limitations. Payment and login examples simulate interactions without a backend. Some demos use external fonts, icons, or images that require an internet connection.

## Adding a project

Create a folder inside the appropriate category using a lowercase name with hyphens. Add its `index.html` and assets, save an optimized screenshot in `assets/previews/`, and add a card to the matching section in the root `index.html`. Update the project counts in the catalog and this README. Use relative paths, `target="_blank"`, and `rel="noopener noreferrer"`.
